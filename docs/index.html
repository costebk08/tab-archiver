How to use

  1. Download the installer for your operating system.
  2. Click Archive All Open Tabs before a restart or reset.
  3. Export the backup file to USB or cloud if you are wiping the computer.

What you get

  • Works on Windows, macOS, and Linux
  • Local history stored in your home folder
  • Open All restores archived websites in one click
  • Optional start-at-login and update notifications in the app
